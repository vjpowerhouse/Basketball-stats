# 
🏀 Team Game Stats — Streamlit Courtside Logger

A lightweight, tap-friendly Streamlit app to track in-game basketball stats for your team.
No spreadsheets needed — edit your roster right in the app, tap quick buttons during play, and export clean box scores.

✨ Features
	•	In-app roster editor (add/remove players inline; jersey # optional)
	•	Quick logging per player: +2, +3, FT, REB, AST, TOV (more events via form)
	•	Auto box score: PTS, FGM/A, 3PM/A, FTM/A, REB, AST, STL, BLK, TOV, PF, %
	•	CSV exports for event log and box score
	•	Optional local save to SQLite (bball_stats.sqlite)
	•	Configurable opponent / date / quarters (e.g., Q1–Q4, OT)
